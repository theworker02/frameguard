## Philosophy

FrameGuard distinguishes:

1. **Measured facts** — Frame 812 took 31.2 ms  
2. **Derived classifications** — likely build-bound  
3. **Heuristic suggestions** — excessive rebuilding may contribute  

Never mix these categories in APIs or docs.
